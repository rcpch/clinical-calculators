# Project Overview

## RCPCH Clinical Calculators

A standardized collection of clinical calculators for healthcare professionals, provided by the Royal College of Paediatrics and Child Health (RCPCH).

## Features

- **RESTful API**: Clean, well-documented API endpoints
- **Web Interface**: Modern, responsive web client built with DaisyUI
- **Standardized Format**: All calculators follow the same input/output pattern
- **Extensible**: Easy to add new calculators
- **Open Source**: Available on GitHub

## Available Calculators

Currently includes:

- **BMI Calculator**: Calculate Body Mass Index
- **HbA1c Converter**: Convert HbA1c between percentage and mmol/mol

## Technology Stack

- **Backend**: FastAPI (Python)
- **Frontend**: DaisyUI + Tailwind CSS
- **Testing**: pytest
- **Deployment**: Docker, GitHub Pages

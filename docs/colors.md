# RCPCH Brand Colors

## Main Brand

- **RCPCH Dark Blue**: `#0D0D58`
- **RCPCH Bright Blue**: `#11A7F2`

## Strategic Growth Areas

Secondary colours should be shown 'linked' to RCPCH Strong Blue

- **RCPCH Strong Blue**: `#3366CC`
- **RCPCH Purple**: `#7159AA`
- **RCPCH Magenta**: `#E00087`
- **RCPCH Strong Green**: `#66CC33`

## Secondary Colours

- **RCPCH Red**: `#E60700`
- **RCPCH Orange**: `#FF8000`
- **RCPCH Yellow**: `#FFD200`
- **RCPCH Gold**: `#C2A712`
- **RCPCH Vivid Green**: `#C8D400`
- **RCPCH Aqua Green**: `#00BDAA`

## Greys

- **RCPCH White**: `#FFFFFF`
- **RCPCH Lightest Grey**: `#F3F3F3`
- **RCPCH Light Grey**: `#D9D9D9`
- **RCPCH Mid Grey**: `#B3B3B3`

- **RCPCH Charcoal**: `#4D4D4D`
- **RCPCH Charcoal Dark**: `#191919`

## Usage in Code

### Tailwind CSS

Add to `tailwind.config.js`:
```javascript
colors: {
  'rcpch-dark-blue': '#0D0D58',
  'rcpch-bright-blue': '#11A7F2',
  'rcpch-strong-blue': '#3366CC',
  'rcpch-purple': '#7159AA',
  'rcpch-magenta': '#E00087',
  'rcpch-strong-green': '#66CC33',
}
```

### CSS Variables

```css
:root {
  --rcpch-dark-blue: #0D0D58;
  --rcpch-bright-blue: #11A7F2;
  --rcpch-strong-blue: #3366CC;
}
```

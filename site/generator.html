Automated Workflow:

  1. Submit PR - Automatically create branch, commit files, run tests, and create pull request

Manual Workflow:

  1. Copy the generated Python code using the copy button above
  2. Create a new branch: git checkout -b calculator/your-calculator-name
  3. Save to calculators/your_calculator.py
  4. Copy the generated Test code and save to tests/test_your_calculator.py
  5. Run tests: pytest tests/test_your_calculator.py
  6. Commit and push: git add . && git commit -m "Add calculator" && git push
  7. Create a pull request on GitHub
